# 내 컴퓨터 점검하기

줌 영상 자동편집을 시작하기 전에 Python, ffmpeg, CapCut 드래프트 폴더가 있는지 확인하는 파일이에요.
**아무것도 설치하거나 바꾸지 않고 확인만 해요.**

## Windows
1. `check_windows.bat` 파일을 내려받아요.
2. 더블클릭해요. (파란 경고창이 뜨면 "추가 정보" → "실행"을 눌러요.)
3. 나온 내용을 복사해서 Claude에게 보내요.

## Mac
1. `check_mac.command` 파일을 내려받아요.
2. 더블클릭해요. 열리지 않으면 파일을 마우스 오른쪽 클릭 → "열기"를 눌러요.
3. 나온 내용을 복사해서 Claude에게 보내요.
